# ChessCoin ♟️

Minimalist chess web app designed for Telegram Mini Apps, with future TON integration in mind.

## MVP
- Responsive chess board
- Legal chess moves
- Local two-player engine-ready structure
- 5-minute game clock
- Move history
- Resign and draw controls
- Mobile-first minimalist interface
- TON wallet connection placeholder

## Roadmap
1. Telegram Mini App integration
2. Real-time 1v1 multiplayer
3. Matchmaking and ELO
4. TON Connect
5. Reward model and compliance review before any real-value crypto flow

No real-money wagering or crypto rewards are enabled in this MVP.
